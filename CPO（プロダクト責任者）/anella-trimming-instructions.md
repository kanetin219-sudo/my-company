# アネラカフェ トリミング予約システム Claude Code 指示書（完全版）

## 概要
アネラカフェ大分店のトリミングサロン向け予約管理システム。
お客様がWebページから予約し、GmailとLINE公式アカウントで自動通知を行う。

---

## 全体の流れ

```
① お客様がWebサイトで予約
        ↓
② お店のGmailに予約通知メール（即時）
        ↓
③ 前日12:00にLINE公式アカウントからリマインド
        ↓
④ 当日8:00にLINE公式アカウントからリマインド
        ↓
⑤ 当日20:00にLINE公式アカウントから口コミ依頼
```

---

## 技術構成

- **フロントエンド**: HTML + CSS + JavaScript（単一HTMLファイル）
- **ホスティング**: GitHub Pages（リポジトリ `kanetin219-sudo/anella-cafe`）
- **バックエンド**: Google Apps Script
- **データ保存**: Googleスプレッドシート
- **メール通知**: Gmail（GASのMailApp使用）
- **LINE通知**: LINE公式アカウント Messaging API（Push Message）
- **自動実行**: GASのトリガー機能（時間指定で自動実行）
- **対象端末**: iPad（Safari）・PC

## 画面構成

### お客様側（予約フォーム）`trimming-reserve.html`

**ステップ形式（戻るボタンあり）**

**STEP 1：⑤ 希望コース選択**
- シャンプーコース / カットコースを大きいボタンでタップ選択
- 選択したコースの基本内容（含まれるメニュー）を表示

**STEP 2：② 犬種・猫種と料金確認**
- 犬種・猫種プルダウン（全リスト）
- 選択と同時に料金を自動表示
- 「その他」選択時は自由入力欄を表示
- カットコースが存在しない犬種はシャンプーコースのみ表示し、カットコースを選んでいた場合は自動でシャンプーコースに変更してアラートを出す

**STEP 3：オプション選択**
- チェックボックスで複数選択可
- 選択のたびに合計金額をリアルタイム表示

**STEP 4：担当者・日時選択**
- 担当者：スタッフA / スタッフB / どちらでも可
- 日付：カレンダーUIで選択（今日から2ヶ月先まで）
- 時間：プルダウン（60分刻み・全日10:00〜15:00）
  - 選択肢：10:00 / 11:00 / 12:00 / 13:00 / 14:00 / 15:00
- すでに予約が入っている時間はグレーアウト

**STEP 5：ペット・お客様情報入力**

ペット情報：
- ② 犬種・猫種（テキスト入力・必須）
- ③ 性別（プルダウン：男の子 / 女の子・必須）
- ④ 体重（プルダウン：〜3kg / 3〜5kg / 5〜10kg / 10kg〜・必須）
- ⑥ 毛玉の有無（プルダウン：なし / 少しあり / 多めにあり・必須）
- ⑦ 当店の利用経験（プルダウン：初めて / 2回目 / 3回目 / 4回目以上・必須）
- ⑧ 年齢（プルダウン：1歳未満 / 1〜3歳 / 4〜7歳 / 8〜10歳 / 11歳以上・必須）
- ⑨ わんちゃん・猫ちゃんのお名前（テキスト・必須）
- ⑩ 1年以内の混合・狂犬病ワクチン接種の有無（プルダウン：接種済み（証明書持参できる） / 接種済み（証明書なし） / 未接種・必須）
  ※「接種済み（証明書なし）」または「未接種」を選択した場合は警告メッセージを表示：
  「⚠️ 接種証明が確認できない場合、ご予約をお断りしております。必ず証明書をご持参ください。」
- ⑪ スタッフに伝えておきたいこと（テキスト・任意）

お客様情報：
- ⑨ 飼い主様のお名前（テキスト・必須）
- ⑫ ご連絡先のお電話番号（テキスト・必須）
- LINE表示名（テキスト・任意）※リマインド送信のために記載をお願いする旨を表示
- メールアドレス（テキスト・任意）

注意事項の確認（必須チェック欄）：
以下の注意事項を表示し、チェックボックスで同意を必須とする。
チェックなしは予約確定ボタンを非活性。


## LINE Messaging API設定

- LINE Developersでチャンネルアクセストークンを発行
- トークンをGASのスクリプトプロパティに保存（コードに直書きしない）
- Push Message APIを使用してお客様のLINE IDに直接送信
- **前提**: お客様がLINE公式アカウントを友だち追加していること
- 友だち追加URLを予約完了画面に必ず表示する

## カレンダービュー仕様

### `trimming-calendar.html`（予約状況カレンダー）

**パスワード認証あり**

**月表示カレンダー**
- Googleカレンダーのような見た目
- 各日付に予約件数をバッジで表示
- 日付をタップするとその日の予約一覧をモーダル表示

- 時間軸（10:00〜18:00）で予約を表示
- スタッフAは青・スタッフBは緑で色分け
- 予約ブロックをタップすると詳細表示
  - ペット名・飼い主名・コース・担当者・金額

**週表示**
- 横軸：曜日、縦軸：時間帯
- スタッフA・Bを色分け表示

**ステータス別の色分け**
- 予約済み：オレンジ（`var(--primary)`）
- 来店済み：グリーン（`var(--accent)`）
- キャンセル：グレー
