# GPT指示書｜チラシ画像生成プロンプト
## 株式会社オレンジゲート AI業務効率化支援サービス

---

## 【指示の目的】

このプロンプトは、株式会社オレンジゲートのAI業務効率化支援サービスの**チラシ画像をGPT（DALL-E / GPT-4o）に生成させる**ための指示書です。

---

## 【GPTへの指示文（そのままコピーして使用）】

```
以下の内容でA4縦サイズのチラシ画像を作成してください。

■ デザインテイスト
- スタイリッシュ＆プロフェッショナル
- カラーテーマ：オレンジ（メイン）× 白 × 濃紺（アクセント）
- フォント：太めのゴシック体・日本語対応
- 清潔感があり、中小企業の経営者に信頼感を与えるデザイン

■ レイアウト（上から順に）

【ヘッダー部分】
- 背景：オレンジのグラデーション
- キャッチコピー（大きく中央）：
  「その「手作業」、AIに任せてみませんか？」
- サブコピー（小さめ）：
  「個人事業主・中小企業の経営者様へ」

【お悩みセクション】
- 背景：薄いグレー
- 見出し：「こんなお悩みありませんか？」
- 箇条書き（チェックボックスアイコン付き）：
  ✗ 毎日の入力作業に時間を取られている
  ✗ SNS投稿や集客に手が回らない
  ✗ 人件費を増やさずに仕事量を増やしたい
  ✗ DX・AI化を進めたいけど何から始めればいいかわからない

【解決策セクション】
- 背景：白
- 見出し（オレンジ）：「オレンジゲートのAI支援なら解決できます！」
- 4つのアイコン付きカード形式で横並び：
  ① 入力・管理業務 → 自動化
  ② SNS投稿・集客 → 仕組み化（Threads推奨）
  ③ 顧客・予約管理 → 効率化
  ④ 人件費削減    → 少人数で最大成果

【実績セクション】
- 背景：濃紺
- 見出し（白）：「支援実績」
- 4つの実績をアイコン付きで並べる：
  🏪 店舗の入退場管理システム
  👥 顧客管理システム構築
  📱 SNS投稿自動化（Threads推奨）
  ⌨️ 日々の入力業務のAI自動化

【CTAセクション（フッター）】
- 背景：オレンジ
- 大きく目立つテキスト：「まずは無料相談！お気軽にどうぞ」
- 連絡先情報：
  📧 info@orangegate.co.jp
  📞 0985-41-5001
- 会社名：株式会社オレンジゲート

■ 全体の雰囲気
- 見やすく読みやすいこと
- ごちゃごちゃさせず余白を活かしたデザイン
- 「すぐ問い合わせしたくなる」衝動を起こさせるような仕上がり
- 日本語テキストを正確に配置すること
```

## 【補足・バリエーション指示】

### SNS投稿用（正方形）に変える場合
上記プロンプトの冒頭を以下に変更：
```
正方形（1080×1080px）のSNS投稿用チラシ画像を作成してください。
メインキャッチコピーと問い合わせ先のみに絞ったシンプルな構成で。
```

### 横長バナー用に変える場合
```
横長バナー（1200×628px）のFacebook/Threads広告用画像を作成してください。
左側にキャッチコピー、右側に連絡先と会社名を配置してください。
```

- [ ] オレンジ×白×濃紺のカラーが使われているか
- [ ] キャッチコピーが大きく読めるか
- [ ] 連絡先（メール・電話）が正確に記載されているか
- [ ] Threads推奨の記載があるか
- [ ] 全体的に清潔感・信頼感があるか
