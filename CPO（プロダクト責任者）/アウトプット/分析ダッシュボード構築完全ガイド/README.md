# 分析ダッシュボード構築 完全ガイド

個別相談・入会データを可視化する分析ダッシュボードを GitHub Pages で公開するための完全ガイドです。

これを読みながら実行すれば、新しいダッシュボードを作成できます。

## STEP 1: スプレッドシートの準備

### 1.1 新しいスプレッドシートを作成

Google スプレッドシート（https://sheets.google.com）で新しいシートを作成してください。

### 1.2 列の設定

以下の列名を**1行目に入力**してください。**順番と名前は完全に一致させてください**。

| 列番号 | 列名 |
|------|------|
| A | タイムスタンプ |
| B | 実施日 |
| C | 実施内容 |
| D | 担当者 |
| E | お名前 |
| F | 現在の職業 |
| G | 年齢 |
| H | 活動地域 |
| I | 撮影ジャンル |
| J | インスタアカウント |
| K | 目標 |
| L | 人柄 |
| M | 料金案内 |
| N | 入会 |
| O | 検討中の場合の期限 |
| P | 収録データ |
| Q | 特記事項 |
| R | ヒアリングのスライドの内容 |

列Nの「入会」に入力する値は以下のいずれかを使用してください：
- `入会` — 入会確定
- `検討中` — 検討中
- `見送り` — 見送り

### 1.3 データを入力

サンプルデータを2行目以降に入力します。

例：
```
タイムスタンプ: 2026-02-01
実施日: 2026-02-01
実施内容: 個別相談
担当者: 山田
お名前: 田中 花子
現在の職業: フリーランス
年齢: 28
活動地域: 東京
撮影ジャンル: ポートレート
インスタアカウント: @hanako_photo
目標: プロ活動
人柄: 明るい
料金案内: 済
入会: 入会
検討中の場合の期限: (空白)
収録データ: (空白)
特記事項: (空白)
ヒアリングのスライドの内容: (空白)
```

### 1.4 スプレッドシートの公開設定（重要）

1. スプレッドシート右上の **「共有」** ボタンをクリック
2. 右下の **「リンクをコピー」** をクリック
3. アクセス権限を **「リンクを知っている全員が閲覧可」** に変更
4. **「共有」** をクリック

**注意**: 公開設定がないと、ダッシュボードがデータを読み込めません。

### 1.5 スプレッドシートIDと GID を確認

スプレッドシートのURLから以下の情報を取得してください：

```
https://docs.google.com/spreadsheets/d/【SHEET_ID】/edit#gid=【GID】
```

- **SHEET_ID**: `d/` と `/edit` の間の部分
- **GID**: `gid=` の後ろの数字

後の手順で必要になります。

## STEP 3: ダッシュボードファイルの配置

### 3.1 index.html をコピー

別フォルダから `index.html` をこのリポジトリにコピーしてください。

※ テンプレートは別ファイル「`index.html（テンプレート）`」を参照してください。

### 3.2 index.html をカスタマイズ

`index.html` をテキストエディタで開いて、以下の部分を編集します。

**編集対象1: SHEET_ID と GID（285行目付近）**

```javascript
const CSV_URL = 'https://docs.google.com/spreadsheets/d/1jdfpZdQcCCZa2A1-cCKBL9yxWUKJ3O7CyEQbQ71Jljc/gviz/tq?tqx=out:csv&gid=1497922169';
```

上記の太字を置き換えてください：
- `1jdfpZdQcCCZa2A1-cCKBL9yxWUKJ3O7CyEQbQ71Jljc` → 自分の SHEET_ID
- `1497922169` → 自分の GID

**編集対象2: ページタイトル（6行目）**

```html
<title>事業名 個別相談 分析ダッシュボード</title>
```

**編集対象3: ナビゲーションタイトル（92行目）**

```html
<span class="navbar-brand">
  <i class="bi bi-camera2 text-primary me-2"></i>事業名 個別相談 分析ダッシュボード
</span>
```

**編集対象4: ステータス判定ロジック（808-813行目）**

スプレッドシート「入会」列に独自の値を使用している場合のみ編集します。

```javascript
function statusGroup(val) {
  if (val === '希望・フォーム回答済' || val === '希望・入金まで完了') return '入会';
  if (val === '検討中' || val === '希望・フォーム未回答')             return '検討中';
  if (val === '見送る'  || val === '案内していないため無し')           return '見送り';
  return '不明';
}
```

必要に応じて値を追加してください。

### 3.3 README.md を配置

別フォルダから `README.md` をコピーするか、以下の内容を使用してください：

```markdown
# [事業名] 個別相談 分析ダッシュボード

GitHub Pages で公開する分析ツールです。Google スプレッドシートのデータを可視化します。

## 機能

- サマリーカード（総相談数・入会数・転換率・検討中件数）
- 月別推移グラフ（相談数/入会数 + 転換率）
- 担当者別実績（相談数・入会数・転換率）
- 撮影ジャンル別（入会者分布）
- 年齢別グラフ
- 月別サマリー（月切り替え可）
- 個別データ一覧（フィルター・検索機能）

## セットアップ

1. スプレッドシートを準備（「分析ダッシュボード構築完全ガイド」参照）
2. このリポジトリの `index.html` で SHEET_ID と GID を設定
3. GitHub Pages で公開

## データ入力について

ダッシュボードはリードオンリーです。データ入力は Google スプレッドシートで行ってください。

「入会」列には以下の値を入力してください：
- `入会` — 入会確定
- `検討中` — 検討中（「検討中の場合の期限」に日付を入れると期限アラートが表示されます）
- `見送り` — 見送り
```

## STEP 4: GitHub Pages の有効化

### 4.1 ファイルをコミット

ターミナルで実行：

```bash
git add index.html README.md
git commit -m "初回コミット：ダッシュボード公開"
git push origin main
```

### 4.2 GitHub Settings で Pages を有効化

ブラウザで GitHub リポジトリを開き、以下の手順を実行：

1. 右上の **Settings** タブをクリック
2. 左のメニューから **Pages** をクリック
3. **Branch** で `main` / `root` を選択
4. **Save** をクリック

1〜2分で公開されます。

### 4.3 公開 URL を確認

Settings > Pages に以下の形式で URL が表示されます：

```
https://【ユーザー名】.github.io/【リポジトリ名】/
```

このURL にアクセスしてダッシュボードが表示されることを確認してください。

## STEP 5: カスタマイズ

### 5.1 色をカスタマイズ

`index.html` の15-20行目の `<style>` セクションで色を変更できます：

```css
:root {
  --primary: #4F46E5;      /* 青系 */
  --success: #059669;      /* 緑系 */
  --warning: #D97706;      /* 橙系 */
  --danger: #DC2626;       /* 赤系 */
}
```

### 5.2 グラフの種類を変更

以下の関数でグラフ設定を変更できます：
- `updateMonthlyChart()` — 月別推移グラフ
- `updateGenreChart()` — ジャンル分布（ドーナツ→棒グラフに変更可）
- `updateAgeChart()` — 年齢別グラフ

### 5.3 表示する列を変更

テーブル部分（254-269行目）で表示列を変更できます。例えば「現在の職業」を追加する場合：

```html
<th class="text-nowrap small">職業</th>
```

を追加して、テーブル行（786-796行目）にも対応する `<td>` を追加してください。

## よくある質問

### Q. 「データの取得に失敗しました」と出る

**原因**: スプレッドシートが公開設定になっていない

**対応**: STEP 1.4 の公開設定を確認してください。「リンクを知っている全員が閲覧可」に設定する必要があります。

### Q. 月フィルターが表示されない

**原因**: データが存在しない、または日付形式が `YYYY-MM-DD` でない

**対応**: スプレッドシートの「実施日」列が `2026-02-01` 形式になっていることを確認してください。

### Q. グラフが表示されない

**原因**: 該当データが存在しない

**対応**: 
- ジャンル別グラフ — 「入会」状態のデータがあるか確認
- 年齢別グラフ — 「年齢」列に数値が入力されているか確認
- 月別グラフ — 「実施日」列の日付形式を確認

### Q. 担当者別実績に誰も表示されない

**原因**: 「担当者」列が空白か、スペルが一致していない

**対応**: スプレッドシートの「担当者」列をチェックしてください。完全一致する必要があります。

### Q. 転換率の計算が合わない

**転換率 = 入会数 ÷ 総相談数 × 100%**

「入会」状態のみカウント対象です。「検討中」「見送り」はカウントされません。

### Q. 期限切れアラートが表示されない

**原因**: 「検討中の場合の期限」列が空白か、日付形式が `YYYY-MM-DD` でない

**対応**: 
- 日付は `2026-02-28` 形式で入力してください
- 今日の日付より過去の日付を入力するとアラート表示されます

### Q. 複数の人で同時に入力しても大丈夫？

はい、Google スプレッドシートなので複数人での同時編集が可能です。ダッシュボードは 1日に複数回開き直すたびに最新データに更新されます。

## トラブルシューティング

### エラー：「リソースが見つかりません」

ダッシュボードが読み込めない場合：

1. **GitHub Pages が有効化されているか確認**
   - Settings > Pages をチェック
   - Branch が `main / root` か確認
   - 緑のチェックマークが表示されているか確認

2. **SHEET_ID と GID が正しいか確認**
   - `index.html` の 285行目を確認
   - スプレッドシートの URL と一致しているか確認

3. **スプレッドシートが公開設定か確認**
   - スプレッドシート右上の「共有」をクリック
   - 「リンクを知っている全員が閲覧可」になっているか確認

### エラー：「データが空です」

1. スプレッドシートにデータが入力されているか確認
2. 1行目（ヘッダー）が正しい列名になっているか確認
3. 公開設定を確認

### ダッシュボードに古いデータが表示される

ブラウザのキャッシュをクリアしてください：
- Chrome: Ctrl+Shift+Delete（Windows）/ Cmd+Shift+Delete（Mac）
- または、ダッシュボード右上の「更新」ボタンをクリック

### グラフが崩れて表示される

ブラウザウィンドウをリサイズするか、F5 キーでリロードしてください。

### インスタグラムリンクが機能しない

「インスタアカウント」列に `@` 記号を含めて入力してください。例: `@hanako_photo`

## テクニカルサポート

問題が解決しない場合は以下をチェックしてください：

- ブラウザのコンソール（F12 → Console タブ）にエラーが出ていないか
- スプレッドシートの URL が HTTP（セキュア）か HTTPS か確認
- VPN や特殊なネットワーク接続を使用していないか
