# 分析ダッシュボード クイックスタート

「分析ダッシュボードを作って」と指示するときに使用するチェックリストです。

---

## 📋 指示メモ

以下の情報を用意して指示します：

```
【事業名】のダッシュボードを作ってください。

【スプレッドシート情報】
- URL: https://docs.google.com/spreadsheets/d/【SHEET_ID】/edit#gid=【GID】
- 公開設定: リンクを知っている全員が閲覧可に設定済み ✓

【ダッシュボード公開設定】
- GitHub リポジトリ名: 【リポジトリ名】
- URL: https://【ユーザー名】.github.io/【リポジトリ名】/

【カスタマイズ】
- ナビゲーションタイトル: 「【事業名】個別相談 分析ダッシュボード」
- アイコン: 📷（またはアイコン指定）
- 色: デフォルト（またはカスタムカラーコード）
- スプレッドシートの「入会」列の値: 入会/検討中/見送り（またはカスタム値）

添付ファイル:
- 分析ダッシュボード構築完全ガイド（全ドキュメント）
```

## ✅ セットアップチェックリスト（作業者用）

### STEP 1: スプレッドシートの準備

- [ ] スプレッドシートが存在する
- [ ] 列名がすべて一致している（「分析ダッシュボード構築完全ガイド」の列構成表を確認）
- [ ] データが2行目以降に入力されている
- [ ] 公開設定: 「リンクを知っている全員が閲覧可」になっている
- [ ] SHEET_ID を確認した
- [ ] GID を確認した

### STEP 2: GitHub リポジトリ作成

- [ ] GitHub で新しいリポジトリを作成した（推奨名: `【事業名】-analytics`）
- [ ] リポジトリをローカルにクローンした
- [ ] `git config --global user.name` と `user.email` が設定されている

### STEP 3: ファイル準備

- [ ] `index.html` をテンプレートからコピーした
- [ ] `index.html` の SHEET_ID と GID を置き換えた（34-35行目）
- [ ] `index.html` のページタイトルを置き換えた（7行目）
- [ ] `index.html` のナビゲーションタイトルを置き換えた（53行目）
- [ ] `index.html` の statusGroup 関数をカスタマイズした（必要な場合のみ）
- [ ] `README.md` をコピーした

### STEP 4: GitHub へアップロード

- [ ] ファイルをコミットした
  ```bash
  git add index.html README.md
  git commit -m "初回コミット：ダッシュボード公開"
  git push origin main
  ```

### STEP 5: GitHub Pages 設定

- [ ] Settings > Pages を開いた
- [ ] Branch: `main` / `root` を選択した
- [ ] 「Save」をクリックした
- [ ] 1-2分待機してから URL にアクセスした
- [ ] ダッシュボードが表示されていることを確認した

### STEP 6: 動作確認

- [ ] スプレッドシートのデータが表示されている ✓
- [ ] グラフが表示されている ✓
- [ ] 月フィルターが動作している ✓
- [ ] 名前検索が動作している ✓
- [ ] 「更新」ボタンをクリックして最新データが反映されることを確認した ✓

## 🎯 よくあるトラブル対応

### 問題: 「データの取得に失敗しました」エラー

**原因**: スプレッドシートが公開設定になっていない

**対応**:
1. スプレッドシートを開く
2. 右上の「共有」をクリック
3. 「リンクを知っている全員が閲覧可」に変更
4. ダッシュボードをリロード（F5キー）

### 問題: グラフが表示されない

**原因**: 該当する条件のデータがない

**対応**:
- ジャンル別グラフ → 「入会」状態のデータで「撮影ジャンル」が未記入
- 年齢別グラフ → 「年齢」列に数値が入っていない
- 月別グラフ → 「実施日」の日付形式が `YYYY-MM-DD` でない

→ スプレッドシートをチェックして修正

### 問題: ページが真っ白で何も表示されない

**原因**: ブラウザのキャッシュが古い、またはJavaScriptエラー

**対応**:
1. Ctrl+Shift+Delete（Windows）/ Cmd+Shift+Delete（Mac）でキャッシュをクリア
2. F12 キーでコンソールを開いてエラーがないか確認
3. SHEET_ID と GID が正しいか確認

### 問題: GitHub Pages のデプロイが完了しない

**原因**: Branch 設定がデフォルトのままになっている

**対応**:
1. Settings > Branches を確認
2. Default branch が `main` か確認
3. Settings > Pages で Branch が `main / root` か確認

## 💡 ベストプラクティス

### 入会値の命名規則

スプレッドシート側で複雑な値を使う場合でも、`statusGroup()` 関数で正確に分類することが重要です。

**例：複数の入会パターン**
```javascript
// スプレッドシートの値: 「希望・フォーム回答済」「希望・入金まで完了」
// ダッシュボード分類: 「入会」

if (val === '希望・フォーム回答済' || val === '希望・入金まで完了') {
  return '入会';
}
```

### 日付入力のルール

- スプレッドシートでセルを「日付」型に設定する
- 手入力する場合は必ず `YYYY-MM-DD` 形式で入力
- Google スプレッドシートの自動フォーマットに任せない

### GitHub コミットメッセージ

初期:
```
初回コミット：ダッシュボード公開
```

更新時:
```
設定: ナビゲーションタイトルを「XX」に変更
設定: 色をカスタマイズ
```
