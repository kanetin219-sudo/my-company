# 分析ダッシュボード構築 完全ガイド セット

このフォルダには、新しい「分析ダッシュボード」を作成・カスタマイズするために必要なすべてのドキュメントが含まれています。

---

## 📂 ファイル構成

```
分析ダッシュボード構築完全ガイド/
├── 00_はじめにお読みください.md（このファイル）
├── README.md（メインの手順書）
├── クイックスタート.md（指示する側用のチェックリスト）
├── 設定ガイド.md（カスタマイズ方法の詳細）

```

---

## 🎯 このセットの使い方

### パターン① 自分で作る場合

1. **README.md** を上から順に読む
2. STEP 1 〜 STEP 5 を実行
3. **設定ガイド.md** を参考にカスタマイズ

**必要な時間**: 30分〜1時間

---

### パターン② 他の人に「作って」と指示する場合

1. **クイックスタート.md** の「指示メモ」セクションを使用
2. 作業者に以下を送る：
   - このフォルダ全体（またはリンク）
   - 指示メモ + スプレッドシート情報
3. 作業者が **README.md** に従って実装
4. 完成後に **クイックスタート.md** のチェックリストで確認

**必要な時間**: 作業者の経験による（初回30分、経験者10分程度）

---

## 🚀 最小限の手順（5分版）

これだけは必須：

1. **スプレッドシート設定**
   - 列構成を確認（README.md 参照）
   - 公開設定を「リンクを知っている全員が閲覧可」に

2. **GitHub で新規リポジトリ作成**
   - 名前: `【事業名】-analytics`
   - クローン

3. **index.html のカスタマイズ**
   - SHEET_ID と GID を置き換え（34-35行目）
   - ナビゲーションタイトルを置き換え（53行目）

4. **GitHub Pages で公開**
   - Settings > Pages > Branch: main / root

5. **動作確認**
   - URL にアクセスしてダッシュボードが表示されるか確認

## ⚡ よくある質問

### Q. 「作ってください」と指示するときは何を送る？

**答え**: 
1. このフォルダ全体（またはリンク）
2. **クイックスタート.md** の「指示メモ」テンプレートを埋めたもの
3. スプレッドシートの URL

以上です。作業者は README.md に従って進めます。

### Q. カスタマイズ中に詰まった

**答え**: 
1. **設定ガイド.md** の該当セクションを探す
2. 具体例が書いてあります

### Q. スプレッドシートのデータ形式は？

**答え**: README.md の「STEP 1」と **設定ガイド.md** の「スプレッドシートの列構成」セクションを参照してください。

### Q. 「入会」列に独自の値を使いたい

**答え**: **設定ガイド.md** の「『入会』列の値（最重要）」セクション参照。

### Q. GitHub Pages で公開されない

**答え**: **README.md** の「トラブルシューティング」→「エラー：『リソースが見つかりません』」を参照。

## 🎨 このテンプレートの特徴

### できることン

✅ Google スプレッドシートのデータを自動で可視化  
✅ サマリーカード（総数・入会数・転換率など）  
✅ 複数グラフ（月別推移・担当者別・年齢別・ジャンル別）  
✅ フィルター・検索機能（入会状況・月・名前）  
✅ 期限アラート（検討中で期限が近い人を自動通知）  
✅ 1ファイル構成（デプロイ簡単）  
✅ CORS なし（セキュアな公開設定のみで動作）  

### 使用技術

- **フロントエンド**: HTML5 + Bootstrap 5 + Chart.js
- **データ源**: Google スプレッドシート（JSONP 方式）
- **デプロイ**: GitHub Pages（無料）
- **バックエンド**: なし（静的ファイルのみ）
