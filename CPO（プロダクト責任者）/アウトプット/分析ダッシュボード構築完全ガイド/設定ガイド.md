## 📌 スプレッドシートの列構成

ダッシュボード側が期待する列構成は以下の通りです。**順番と名前は完全に一致させてください**。

### 必須列（すべて必須）

| 列 | 型 | 用途 | 入力例 | 注意 |
|---|---|---|---|---|
| タイムスタンプ | 日付 | 相談実施日時 | 2026-02-01 | YYYY-MM-DD形式 |
| 実施日 | 日付 | ダッシュボード表示用 | 2026-02-01 | YYYY-MM-DD形式 必須 |
| 実施内容 | テキスト | 相談内容 | 個別相談 | 自由 |
| 担当者 | テキスト | 相談担当者名 | 山田 | グラフに反映される |
| お名前 | テキスト | 相談者名 | 田中 花子 | 検索・一覧に使用 |
| 現在の職業 | テキスト | 相談者の職業 | フリーランス | 自由 |
| 年齢 | 数字 | 相談者の年齢 | 28 | 年齢グラフに使用 |
| 活動地域 | テキスト | 活動地域 | 東京 | 自由 |
| 撮影ジャンル | テキスト | ジャンル | ポートレート | グラフに反映される |
| インスタアカウント | テキスト | インスタID | @hanako_photo | 検索・リンク化（@含める） |
| 目標 | テキスト | 目標 | プロ活動 | 自由 |
| 人柄 | テキスト | 人柄/特徴 | 明るい | 自由 |
| 料金案内 | テキスト | 案内状況 | 済 | 自由 |
| **入会** | テキスト | **ステータス** | **入会** | ⭐ 重要（下記参照） |
| 検討中の場合の期限 | 日付 | 検討期限 | 2026-06-30 | YYYY-MM-DD形式 |
| 収録データ | テキスト | データURL等 | (空可) | 自由 |
| 特記事項 | テキスト | メモ | (空可) | 自由 |
| ヒアリングのスライドの内容 | テキスト | スライド内容 | (空可) | 自由 |

### ⭐ 「入会」列の値（最重要）

この列がダッシュボードの分類を決定します。**以下の値を完全一致で入力してください**：

| 値 | 分類 | ダッシュボード表示 |
|---|---|---|
| `入会` | 入会 | 緑色ピル「✓ 入会」 |
| `検討中` | 検討中 | 橙色ピル「⏳ 検討中」 |
| `見送り` | 見送り | グレーピル「見送り」 |

**スプレッドシートに独自の値を使用している場合**: `index.html` の `statusGroup()` 関数を編集して対応してください。

例：
```javascript
function statusGroup(val) {
  if (val === '入会' || val === '希望・フォーム回答済') return '入会';
  if (val === '検討中' || val === '希望・フォーム未回答') return '検討中';
  if (val === '見送り' || val === '案内していないため無し') return '見送り';
  return '不明';
}
```

### Q. デモデータを削除したい

ダッシュボードは自動的に実ファイル + エラー時のデモデータ の組み合わせです。

スプレッドシートの公開設定が完了していれば、デモデータは自動的に非表示になります。

## 🔒 スプレッドシート公開設定の確認

### 設定が正しいか確認する方法

1. スプレッドシートを新しいシークレットウィンドウで開く
2. ログアウト状態でアクセスできるか確認

**できない場合**:
- スプレッドシート右上の「共有」をクリック
- 「リンクを知っている全員が閲覧可」に変更
- 「共有」をクリック

### 公開設定なしの場合のエラー

ダッシュボードに黄色いバナーが表示されます：

```
⚠️ データの取得に失敗しました。スプレッドシートの公開設定（リンクを知っている全員が閲覧可）を確認してください。
```

このとき、デモデータが表示されます。

## 📅 日付フォーマット

ダッシュボードが理解できる日付形式は以下のいずれかです：

| 形式 | 例 | ✓判定 |
|---|---|---|
| `YYYY-MM-DD` | `2026-02-01` | ✓ |
| `YYYY/MM/DD` | `2026/02/01` | ✓ |
| Google スプレッシート標準形式 | 日付セル | ✓ |

**注意**: 
- `2/1/2026` （アメリカ形式）は自動認識されません
- セルを日付型にすることを推奨します

## ⚙️ 詳細カスタマイズ

### statusGroup 関数を拡張する場合

スプレッドシートに複雑なステータス値がある場合：

```javascript
function statusGroup(val) {
  // 入会パターン（複数の値を「入会」と判定）
  if (val === '入会' || 
      val === '希望・フォーム回答済' || 
      val === '希望・入金まで完了' ||
      val === '入金確認済') return '入会';
  
  // 検討中パターン
  if (val === '検討中' || 
      val === '希望・フォーム未回答' ||
      val === '調整中') return '検討中';
  
  // 見送りパターン
  if (val === '見送り' || 
      val === '見送る' ||
      val === '案内していないため無し' ||
      val === '予算不足') return '見送り';
  
  return '不明';
}
```

## 📊 データ分析のコツ

### 転換率が低い原因を調べる

1. 「年齢別」グラフで年齢帯ごとの転換率を確認
2. 「撮影ジャンル別」で人気ジャンルを確認
3. 「担当者別」で担当者の実績を確認

### 検討中を次月に成約させるコツ

1. ダッシュボードの「月別サマリー」で期限間近の人を確認
2. 「検討期限」30日以内の人がハイライトされる
3. 期限の前に連絡を取る

### 新しい担当者を育成する場合

「担当者別実績」で:
- 相談数（相談をいくつ取っているか）
- 入会数（実績）
- 転換率（相談の質）

を確認して、指導ポイントを決めることができます。
