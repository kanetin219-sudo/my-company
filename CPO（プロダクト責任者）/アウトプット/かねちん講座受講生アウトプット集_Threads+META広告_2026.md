**次月グルコン**：

### 2️⃣ mitsuyo

**タイトル**：7/16 かねちんさんThreads運用アウトプット

**クライアント状況**：
- スレッツ運用を希望するクライアント
- 少し抱えられてもいることに気付いた

**学んだ具体施策**：

| 施策 | 説明 |
|-----|------|
| **曜日のフック** | 「何」を欲信したいのか → 「どうしてほしい」に求めほしい が大切 |
| **昨頭のフック** | 「〇〇なんですか朝報です！などという掲げ付けものを使用する |
| **時系テキ** | 時系テキなどの要に応じて使い、ツリー方式していくという手法を試す |
| **リーコメント効果** | 10時間後のリーコメで反応がPDCAの回してフォロー、収益増加を目指す |

**実装予定**：
- 教えていただいたことをクライアントさんに共有してThreadsの主な作りをしていこうと思う
- 来月のグルコンも楽しみ

### 3️⃣ ほっしー

**タイトル**：7/16 かねちんさんグルコンアウトプット

**背景**：
- 2年前の育休中にスレッズを始めたが、当時スレッズで付き良くなったママさんと合ったり悩みを共有したりとスレッズは良い印象

**学んだ内容**：
- スレッズ運用を担当することになって、Threads について詳しくなった
- かねちんの話を聞き、スレッズをやらないといけないなぜ理由は → 「ストレスから条件が叶える」「店舗系と採用系がスレッツと相性が良いこと」「スレッツは励かしていればフォロワーが増える」「投稿のツリー方式」「【】を昨頭に入れる」「○○の9割が知らない...と入れる」

**実践で得た気付き**：
- スレッズでアフィリエイトをやってみたいと思っていた
- 運用代行の仕事はまだスタートラインにも立っていないので、1つ1つなしたほうが先でスレッツの提案ができるようになりたい

**今後**：
- スレッズでアフィリエイトをやってみたいと思っていた
- 毎月グルコンに参加して良うことは、みらいさんの講座に入っていなければここまで有益な情報を得ることが難しかったろうなぁ

### 4️⃣ mai

**タイトル**：7/16 かねちんさんグルコンアウトプット

**受講した内容**：
- スレッズはで以前お試しして手伝ったことがあり、その時はAIで作った投稿を添削するという内容
- 呼びかけばかりでこっってるわかわけず「じゃってました」
- 今回具体的な辿る施設や注意点を教えていただき、それぞれ踏まえてまたやってみたいと思いました

**プロフィール 4点セット**：
1. 肩書き + 困苦名
2. 2俎orロゴor背景1色
3. 150字紹介文
4. 誘導先LINE公式1本

**やりがちな NG**：
- 日々のことを書きます ← 誰にも刺さらない
- 絵文字だけ検索、要点把握を整す
- 定期的にリンクを貼らない ← 導ゼロ = 収益ゼロ
- ホーム表示だけ = 評価は「普通」
- タップされてこそ強い信号
- タップされたされるほど自分の求める層に届くか も

**実装予定**：
- 基本最初は手動推奨

## 🎯 受講生から学んだポイント

### Threads 運用での実践学び

| ポイント | 学び |
|---------|------|
| **プロフィール 4点セット** | 肩書き・ロゴor背景・150字紹介・LINE誘導 |
| **昨頭フック 7パターン** | 「何」ではなく「どうしてほしい」の形式が重要 |
| **時系テキ** | 時系列でテキスト内容を変える工夫 |
| **リーコメント効果** | 10時間後のコメント返信で反応が変わる |
| **【】の活用** | 「【】を昨頭に入れる」「○○の9割が知らない」 |
| **ツリー方式** | Threads の特性を生かした投稿方式 |
| **ストレスと親和性** | 店舗系・採用系との相性が良い |

### META 広告運用での実践学び

| ポイント | 学び |
|---------|------|
| **インスタ vs META** | Instagram広告はインスタのみ。META広告は全体管理 |
| **広告リサーチ方法** | 広告ライブラリで競合分析が可能 |
| **テスト重視** | たくさん出して、たくさんテストすることが重要 |
| **結果が正解** | 「結果が出たやり方が正解」という思想 |
| **イベント活用** | イベント集客に相性が良い |
| **美容サロン** | ホットペッパーより安い単価の可能性 |
| **田舎の優位性** | 競合がいないからこそ有効な戦略 |
| **小額スタート** | 少額から始められるハードルの低さ |

## 💡 受講生の共通点（成長パターン）

### 1️⃣ 知識 → 理解への遷移

```
「無知だった」
  ↓
「何が何だかわからなかった」
  ↓
「具体例・実績を聞いて理解した」
  ↓
「自分も試してみたくなった」
```

### 2️⃣ テスト → 実装への道

- **個人のアカウントでテストすることから開始**
- **小額の広告出稿で試す**
- **クライアントへの提案に進む**

### 3️⃣ クライアント対応スキルの向上

- ヒアリング能力の向上
- 複数の選択肢を提案できるようになる
- 「これしかできない」から「複数手法を提案できる」へ進化
