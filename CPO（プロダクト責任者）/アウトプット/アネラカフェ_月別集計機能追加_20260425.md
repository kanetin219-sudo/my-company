# アネラカフェ 月別集計機能追加

作成日: 2026-04-25

---

## 概要

「記録」シートへの書き込みと同時に「月別集計」シートも自動更新するよう、Apps Scriptを拡張する。
HTMLファイルの変更は不要（GASのURLは変わらないため）。

---

## ① 更新版 Apps Script コード

既存のコードを**全て以下に置き換える**。

```javascript
function doGet(e) {
  var spreadsheetId = '1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo';
  var ss = SpreadsheetApp.openById(spreadsheetId);
  var recordSheet = ss.getSheetByName('記録');
  var visit = e.parameter.visit;
  var today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd');
  var thisMonth = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM');

  // ===== 記録シートの更新（既存処理） =====
  var lastRow = recordSheet.getLastRow();
  var todayRow = -1;

  for (var i = 2; i <= lastRow; i++) {
    if (recordSheet.getRange(i, 1).getValue() === today) {
      todayRow = i;
      break;
    }
  }

  if (todayRow === -1) {
    todayRow = lastRow + 1;
    recordSheet.getRange(todayRow, 1).setValue(today);
  }

  var colMap = { '新規': 2, '2回目': 3, '3回目': 4, '4回目以上': 5 };
  var col = colMap[visit];
  if (col) {
    var current = recordSheet.getRange(todayRow, col).getValue() || 0;
    recordSheet.getRange(todayRow, col).setValue(current + 1);
  }

  // ===== 月別集計シートの更新（追加処理） =====
  var monthSheet = ss.getSheetByName('月別集計');

  // シートが存在しない場合は自動作成
  if (!monthSheet) {
    monthSheet = ss.insertSheet('月別集計');
    var headers = [['月', '新規', '2回目', '3回目', '4回目以上', '合計来店数']];
    monthSheet.getRange(1, 1, 1, 6).setValues(headers);
    monthSheet.getRange(1, 1, 1, 6).setFontWeight('bold');
    monthSheet.setFrozenRows(1);
  }

  // 今月の行を検索
  var monthLastRow = monthSheet.getLastRow();
  var thisMonthRow = -1;

  for (var j = 2; j <= monthLastRow; j++) {
    if (monthSheet.getRange(j, 1).getValue() === thisMonth) {
      thisMonthRow = j;
      break;
    }
  }

  // 今月の行がなければ新規作成（初期値0で埋める）
  if (thisMonthRow === -1) {
    thisMonthRow = monthLastRow + 1;
    monthSheet.getRange(thisMonthRow, 1).setValue(thisMonth);
    monthSheet.getRange(thisMonthRow, 2, 1, 4).setValues([[0, 0, 0, 0]]);
  }

  // 該当列をインクリメント
  if (col) {
    var monthCurrent = monthSheet.getRange(thisMonthRow, col).getValue() || 0;
    monthSheet.getRange(thisMonthRow, col).setValue(monthCurrent + 1);
  }

  // 合計来店数を再計算（新規＋2回目＋3回目＋4回目以上）
  var b = monthSheet.getRange(thisMonthRow, 2).getValue() || 0;
  var c = monthSheet.getRange(thisMonthRow, 3).getValue() || 0;
  var d = monthSheet.getRange(thisMonthRow, 4).getValue() || 0;
  var e2 = monthSheet.getRange(thisMonthRow, 5).getValue() || 0;
  monthSheet.getRange(thisMonthRow, 6).setValue(b + c + d + e2);

  return ContentService.createTextOutput('ok').setMimeType(ContentService.MimeType.TEXT);
}


// ===== 過去データ再集計（初回1回だけ手動実行する） =====
// Apps Scriptエディタ上部の「実行」ボタンで実行する
// 「記録」シートの全データをもとに「月別集計」を一から作り直す
function rebuildMonthlySheet() {
  var spreadsheetId = '1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo';
  var ss = SpreadsheetApp.openById(spreadsheetId);
  var recordSheet = ss.getSheetByName('記録');

  // 既存の月別集計シートを削除して再作成
  var existing = ss.getSheetByName('月別集計');
  if (existing) ss.deleteSheet(existing);
  var monthSheet = ss.insertSheet('月別集計');

  var headers = [['月', '新規', '2回目', '3回目', '4回目以上', '合計来店数']];
  monthSheet.getRange(1, 1, 1, 6).setValues(headers);
  monthSheet.getRange(1, 1, 1, 6).setFontWeight('bold');
  monthSheet.setFrozenRows(1);

  var lastRow = recordSheet.getLastRow();
  var monthMap = {}; // { 'yyyy/MM': { 新規:0, 2回目:0, 3回目:0, 4回目以上:0 } }

  for (var i = 2; i <= lastRow; i++) {
    var dateVal = recordSheet.getRange(i, 1).getValue();
    if (!dateVal) continue;

    var dateStr = Utilities.formatDate(new Date(dateVal), 'Asia/Tokyo', 'yyyy/MM/dd');
    var month = dateStr.substring(0, 7); // yyyy/MM

    if (!monthMap[month]) {
      monthMap[month] = { '新規': 0, '2回目': 0, '3回目': 0, '4回目以上': 0 };
    }

    var cols = ['新規', '2回目', '3回目', '4回目以上'];
    for (var k = 0; k < cols.length; k++) {
      var val = recordSheet.getRange(i, k + 2).getValue() || 0;
      monthMap[month][cols[k]] += val;
    }
  }

  // 月順にソートして書き込み
  var months = Object.keys(monthMap).sort();
  for (var m = 0; m < months.length; m++) {
    var mo = months[m];
    var d = monthMap[mo];
    var total = d['新規'] + d['2回目'] + d['3回目'] + d['4回目以上'];
    monthSheet.appendRow([mo, d['新規'], d['2回目'], d['3回目'], d['4回目以上'], total]);
  }

  Logger.log('月別集計の再構築が完了しました。');
}
```

## ③ スプレッドシート・GAS の設定手順

### Step 1: Apps Scriptを開く

1. `anellacafeoita@gmail.com` でログイン（シークレットモード推奨）
2. スプレッドシートを開く
   - URL: `https://docs.google.com/spreadsheets/d/1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo/edit`
3. メニュー「拡張機能」→「Apps Script」をクリック

### Step 2: コードを置き換える

1. エディタに表示されている既存コードを**全て削除**
2. 上記「① 更新版 Apps Script コード」を**丸ごとペースト**
3. 保存（Ctrl+S または ⌘+S）

### Step 3: 過去データを再集計する（初回のみ）

> 既存の「記録」シートにすでにデータがある場合に実行する。
> 初めて使う場合はスキップ可。

1. エディタ上部の関数選択プルダウンで `rebuildMonthlySheet` を選択
2. 「実行」ボタンをクリック
3. 初回は権限確認ダイアログが出る → 「権限を確認」→「anellacafeoita@gmail.comで続行」→「許可」
4. 実行完了後、スプレッドシートに「月別集計」シートが作成されていることを確認

### Step 4: 新しいバージョンでデプロイする

1. 右上「デプロイ」→「デプロイを管理」
2. 既存のデプロイの右にある鉛筆アイコン（編集）をクリック
3. バージョンを「新しいバージョン」に変更
4. 「デプロイ」をクリック
5. URLが変わっていないことを確認（変わっていればHTMLも更新が必要だが、通常は変わらない）

### Step 5: 動作確認

1. iPadのSafariでHTMLを開く
2. テスト来客を1組会計する
3. スプレッドシートの「記録」シートと「月別集計」シート両方に記録されていることを確認

## 注意事項

- `rebuildMonthlySheet` は**初回1回だけ**実行する（毎回実行するとシートが作り直されてしまう）
- 通常運用では `doGet` が自動で月別集計を更新するため、手動操作は不要
- デプロイURL変更時はHTMLの `GAS_URL` 定数も合わせて更新すること
