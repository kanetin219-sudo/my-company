# 週報システム テストガイド

## テスト概要

このガイドは、実装されたシステムをテストするための手順を説明しています。

---

## 前提条件

✅ GitHub Pages で weekly-report.html が公開されている  
✅ GAS Web App が デプロイされ、URL が取得できている  
✅ Claude APIキーが有効  
✅ LINE Messaging API トークンが有効

---

## テスト Step 1: API 設定のテスト

### 1-1. ツールを開く

```
https://kanetin219-sudo.github.io/anella-cafe/weekly-report.html
```

### 1-2. API 設定を入力

1. 「⚙️ API設定」ボタンをクリック
2. 以下を入力：
   - **ログインパスワード**: `test123`
   - **Claude APIキー**: `sk-xxxxx...`（実際のキー）
   - **GAS Web App URL**: `https://script.google.com/macros/d/...usercontent`
   - **LINE トークン**: `Bearer ...`（実際のトークン）
3. 「設定を保存」をクリック

**期待結果**: 「設定を保存しました ✓」トースト表示

---

## テスト Step 2: ログイン・画面遷移のテスト

### 2-1. ログイン

1. パスワード欄に `test123` を入力
2. 「ログイン」ボタンをクリック

**期待結果**:
- ログイン画面が消える
- メイン画面（写真アップロード画面）が表示される

### 2-2. 画面要素の確認

メイン画面に以下が表示されているか確認：
- 🐾 アネラカフェ ロゴ
- 📸 写真をアップロード セクション
- 📝 週報を生成する ボタン

**期待結果**: すべてのUI要素が表示される

---

## テスト Step 3: 写真アップロードのテスト

### 3-1. テスト画像の準備

以下のいずれかで テスト画像を用意：
- アネラカフェの写真（実物）
- 犬・猫の写真
- 風景写真

### 3-2. アップロード

1. 「📸 写真をアップロード」セクションをクリック
2. ファイル選択ダイアログから画像を選択
3. または、ドラッグ&ドロップで画像をドロップ

**期待結果**:
- サムネイルが表示される
- 「メイン」「削除」ボタンが表示される

### 3-3. 複数枚のアップロード

1. もう1〜4枚の画像をアップロード（最大5枚）
2. 各写真に「メイン」「削除」が表示

**期待結果**: 最大5枚まで追加可能

### 3-4. メイン写真の変更

1. 任意の写真の「メイン」ボタンをクリック
2. その写真に「メイン」バッジが表示される

**期待結果**: 選択した写真が「メイン」に変わる

---

## テスト Step 4: Claude API 呼び出しのテスト

### 4-1. 週報生成

1. 最大5枚の写真がアップロードされている状態で、「📝 週報を生成する」をクリック
2. ボタンがローディング状態に変わる（「生成中...」）
3. 数秒待つ

**期待結果**:
- エラーが出ない
- プレビュー画面に遷移する
- 3つのテキストセクションが表示される：
  - 「今週のひとこと」
  - 「今週の子たち🐶🐱」
  - 「みんなの作業風景✨」

### 4-2. テキストの確認

プレビュー画面のテキストを確認：
- 50〜80文字程度か
- 文法的に正しいか
- 前向きなトーンか

**期待結果**: AI が自然な日本語テキストを生成している

---

## テスト Step 5: テキスト編集のテスト

### 5-1. テキストをタップ

1. 「今週のひとこと」のテキストをタップ
2. モーダルが開く

**期待結果**:
- テキストがテキストエリアに表示される
- 「保存」「キャンセル」ボタンが表示される

### 5-2. 編集

1. テキストを修正
2. 「保存」をクリック

**期待結果**:
- モーダルが閉じる
- プレビュー画面のテキストが更新される
- 「保存しました ✓」トースト表示

### 5-3. キャンセル

1. 別のテキストをタップ
2. 「キャンセル」をクリック

**期待結果**: モーダルが閉じ、テキストは変更されない

---

## テスト Step 6: LINE 配信のテスト

### 6-1. 配信実行

1. プレビュー画面の「💬 LINEに配信する」をクリック
2. 確認ダイアログが表示される
3. 「OK」をクリック
4. ボタンがローディング状態に変わる

**期待結果**:
- エラーが出ない
- 「LINE配信完了しました！ ✓」トースト表示
- メイン画面に戻る

### 6-2. LINE で確認

1. アネラカフェ大分店の LINE 公式アカウントを友だち追加
2. 配信されたメッセージを確認

**期待結果**:
- Flex Message がフォーマットされて表示される
- 写真が表示される
- 3つのテキストセクションが表示される

---

## テスト Step 7: エラーハンドリングのテスト

### 7-1. 写真なしで生成を試みる

1. ログイン
2. 写真をアップロードせず「📝 週報を生成する」をクリック

**期待結果**: 「写真を1枚以上アップロードしてください」トースト表示

### 7-2. API キー無効でテスト

1. API設定で無効なキーを入力
2. 写真をアップロード
3. 「📝 週報を生成する」をクリック

**期待結果**: エラーメッセージが表示される
