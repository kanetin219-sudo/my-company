## 2. 【Lゼロ】リール台本用ナレッジ

### ターゲット
- **主ターゲット**：20〜40代の女性・副業希望のママ層
- **サブターゲット**：在宅ワークを探している会社員・フリーランス志望

### コアな悩み（フックに使える）
- 「子育てしながら稼げる仕事がない」
- 「副業を始めたいけど何をすればいいかわからない」
- 「会社を辞めたいけど収入がなくなるのが怖い」
- 「スキルがないと思っている」

### 訴求軸（ベネフィット）
- **在宅で稼げる** ← 場所・時間を選ばない
- **子育てしながらでもできる** ← ママでも実績多数
- **ゼロから始められる** ← スキル不要でスタート
- 受講生の成果・ビフォーアフターをコンテンツ化（許可取り必須）

### 実績・証拠として使えるもの
- Discordコミュニティ運営中（「成果分析クン」ボット稼働）
- 顧問サービスと組み合わせた伴走型サポート
- かねちん自身が経営者・SaaS開発者でもあるという信頼性

### CTA（行動喚起）
- プロフィールのリンクから無料相談へ
- LINEへの誘導（公式LINE登録）

### NGワード・注意事項
- 「絶対稼げる」「誰でも月○万円」などの断言表現は禁止
- 個人の成果には個人差があるという表記を忘れない
- 受講生の顔出し・名前は必ず本人許可を取ってから使用

## 3. 【SaaS・顧問サービス（オレンジゲート）】リール台本用ナレッジ

### ターゲット
- **主ターゲット**：個人事業主〜中小企業の社長・経営者
- **サブターゲット**：DX・AI化を検討しているが何から始めるかわからない事業者

### コアな悩み（フックに使える）
- 「毎日の入力作業に時間を取られている」
- 「SNS投稿や集客に手が回らない」
- 「人件費を増やさずに仕事量を増やしたい」
- 「DX・AI化を進めたいけど何から始めればいいかわからない」

### 訴求軸（ベネフィット）
- **業務の自動化・効率化** → 作業時間を最大70%カット
- **SNS集客の仕組み化** → AI×マーケティングで担当者の負担ゼロ
- **少人数で最大のアウトプット** → 人件費を増やさず成果を出す
- **"使える仕組み"まで伴走** → 導入して終わりじゃない

### 自社実績（具体的に使えるネタ）

これがめちゃくちゃ強い武器っちゃ。**自社（アネラカフェ）で実際に全部やってる**：

| 自社で作ったもの | 解決した課題 |
|---|---|
| トリミング予約システム | 電話対応・手書き予約ゼロへ |
| 送迎管理システム | 週間スケジュール・ドライバー管理を自動化 |
| 在庫管理表（42品目） | Excelでの手入力・集計作業ゼロへ |
| レジ締めチェックシート | レジ差異・金庫差異の自動計算 |
| 収支管理システム | 月次スプレッドシート転記が自動化 |
| SNS投稿自動化 | 毎日2本の投稿を完全自動（Claude AI+GAS） |
| 工賃明細書生成ツール | 20名分の明細書をドラッグ&ドロップで一括生成 |
| META広告データ自動取得 | 毎朝7時にスプレッドシートへ自動反映 |

→ **「自分の会社でまずやってみて、うまくいったものをお客さんに提供している」**というストーリーが最強のフック

### 支援実績（対外向け）

## 4. リール構成の型（参考）

### 型①「自分事化」フック型
```
【0〜3秒】フック
「〇〇で悩んでませんか？」「これやってる社長、まじで損してます」

【3〜15秒】共感＋問題提起
「こんな状態になってないですか？（具体的なシーン）」

【15〜40秒】解決策・実績
「うちではこうやって解決しました（具体的な数字・Before/After）」

【40〜60秒】CTA
「気になる方はプロフのリンクから無料相談どうぞ」
```

### 型②「ビフォーアフター」型
```
【0〜3秒】Before（痛い状態）をビジュアルで見せる
【3〜30秒】After（解決後）を具体的な数字で見せる
【30〜60秒】どうやって変わったか＋CTA
```

### 型③「暴露・本音」型
```
【0〜3秒】「ぶっちゃけ言います」「知らないと損する話」
【3〜45秒】業界の常識・みんながやってない方法を具体的に話す
【45〜60秒】「詳しくはプロフから」
```

## 5. コンテンツ制作の絶対ルール

- 事実と意見は明確に分けて記載
- 「絶対」「確実」「誰でも」などの断定表現は禁止
- 個人の成果には個人差の旨を添える
- 誤字脱字・数値の正確性を必ず確認
- ネガティブ・炎上リスクのある表現は使用しない
- 利用者・顧客情報は絶対に無断掲載しない
