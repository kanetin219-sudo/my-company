## 3. リール制作：撮影の基本（BUZZ BOOSTインスタ講座より）

### カメラ・動画の基本設定
- **サイズ**：1080×1920px（縦向き・スマホ全画面）
- **比率**：16:9（リール・TikTok・Shorts共通）
- **解像度**：1080P / 60fps（4Kは圧縮されるので不要）
- **グリッド線ON**：水平・垂直を意識した構図が品質を大きく変える

### 撮影のNG例（やりがちな失敗）
| NG | 対策 |
|-----|------|
| 雑音がある素材 | 撮影前に換気扇・エアコン・テレビをオフ。外の音がある時は窓を閉める |
| ピントが合っていない | 撮影前に主役を1回タップしてピントロック。手元を映す時は手を止める |
| 暗すぎる素材 | 自然光を最大活用（窓側で撮影）。暗い室内はリングライトで補助照明 |
| 背景がごちゃごちゃ | 見せたい世界観に合った背景に整える。余白を意識 |
| 余白ゼロで窮屈な画面 | 上下左右の余白を確保。詰め込みすぎない |

### 明るさが全て
- リールの品質は「明るさ」で8割決まる
- 自然光あり vs なし：色の鮮やかさ・ツヤ感・見やすさが全然違う
- 自然光が使えない時間帯はリングライト必須

## 4. リール制作：ファン化リールの概念（BUZZ BOOSTインスタ講座より）

### ファン化リールとは
**自分の想い・体験・経験・感想を乗せて、フォロワーさんに届いた時に「共感」か「なりたい未来」を魅せるリール**

- 情報だけを並べる「情報リール」との違い：フォロワーが「あなた個人」を好きになる
- 「自分の好きなこと」を語ればいい ≠ 自己満投稿でもいい
- 大前提：**「誰かのためになるか」「需要があるか」を確認すること**

### 情報リール vs ファン化リールの違い
| | 情報リール | ファン化リール |
|--|----------|--------------|
| 内容 | 機能・メリットを並べる | なぜ使ったか（きっかけ）＋使った結果（ベネフィット） |
| 例 | 「高画質で4K撮影可能！」 | 「子どもの運動会でゴールの瞬間の笑顔を撮れた」 |
| 効果 | 広くリーチする | 見ている人がファンになる・共感する |

### ファン化リールの構成要素

**投稿の見せ方（全投稿共通）：**
- 自分の姿を映す（後ろ姿でも自分にしか持てない姿を見せる）
- 服装・髪型にこだわりを持つ（フォロワーにイメージを定着させる）
- インテリア・背景を意識する（見せたい世界観の色味が超重要）
- **自分の声でアフレコをする**（ファン化には自分の声が必須・機械音声より断然強い）
- 世界観に合ったフォントを選ぶ
- アカウントに合ったBGMを選ぶ（自分のジムだったらどんな音楽？で考える）

**投稿内容（1投稿ごとに変える）：**
- なぜ紹介しようと思ったか（きっかけ）
- 最高の投稿内容
- 使った結果どうなったか（ベネフィット）

### ファン化リールのNGと正しい使い方
| NG | 正しい姿 |
|-----|---------|
| 好きを一方的に語る | フォロワーの需要があるものに絞る |
| 引きで撮ればいいと思い込む | 距離・角度を使い分ける（大・中・小3パターン） |
| ファン化リールだけに振り切る | **情報リール（バズリール）×ファン化リールを混在させる** |
| マネタイズを後回しにする | **ファン化しながら同時並行でマネタイズする** |

### ファン化リールのマネタイズ導線
```
リール（ファン化）
  ↓
自動返信DM → プロフィールリンク → ハイライト
  ↓
ストーリーズ（日常ファン化）
  ↓
LINE公式（DM・ステップ配信）
  ↓
セールス（商品・サービス）
```
**リール単体でマネタイズは完結しない**。リールはファン化と認知が目的。

## 5. リール台本の型（4種）

### 型①「自分事化フック」型（最もオーソドックス）
```
【0〜3秒】フック（悩みをストレートにぶつける）
 例：「これやってる社長、まじで損してます」
 例：「副業始めたいと思ってる人、ちょっと待って」

【3〜15秒】共感・問題提起（具体的なシーン描写）

【15〜40秒】解決策・実績（具体的な数字・Before/After）

【40〜60秒】CTA
```

### 型②「ビフォーアフター」型
```
【0〜3秒】「ビフォー」の文字を出す → これだけで視聴者が引き戻される
【3〜30秒】After（解決後）を具体的な数字で見せる
【30〜60秒】どうやって変わったか + CTA
```

### 型③「暴露・本音」型
```
【0〜3秒】「ぶっちゃけ言います」「知らないと損する話」
【3〜45秒】業界の常識・みんながやってない方法を具体的に話す
【45〜60秒】「詳しくはプロフから」
```

### 型④「ネガティブ感情開示・ヒーローズジャーニー」型（ファン化が爆発する）
```
【0〜3秒】「ブチ切れてます」「正直しんどかった」
【3〜30秒】エピソードを本音で語る（どん底 → 這い上がり）
【30〜60秒】そこから気づいたこと + CTA
```
※ **有益5：背景（感情）1の比率で混ぜる**のが理想

### 1分リールの時間配分（BUZZ BOOST型）
```
冒頭フック：3秒
悩み/きっかけ：13秒
価値提供（主コンテンツ）：34秒
ベネフィット：5秒
CTA：5秒
```

## 6. フックの作り方（冒頭3秒が全て）

### 効くフックのパターン
- 「〇〇してる人、絶対損してます」
- 「〇〇で悩んでませんか？」
- 「これ知らないと〇〇万円損します」
- **「言語化されていない悩み」を突く**
  - × 「腹筋割りたい人へ」
  - ○ 「腹筋したらお腹の真ん中だけ出る」← コメント「私もです」が爆増する
- 「ビフォー」の文字を出す（ビフォーアフター型の鉄板）
- バズった過去投稿のスクショを冒頭に貼る（トークリール冒頭スクショ技）
- 「〇〇している40代女性へ」と冒頭にペルソナを書く（Threadsにも有効）
- 「建築士の私が」「100人以上痩せさせてきた」など権威性を冒頭に入れる

## 7. アルゴリズム攻略の実践知識（マスター合宿2026より）

### トライアルリール活用（フォロワー増加の最重要手段）
- 既存フィードを汚さず**非フォロワー層だけ**にリーチできる機能
- **冒頭だけ変えた3パターンをABテスト** → 伸びたものを本投稿
- 1コンテンツを4回分活用できる
- 週1サイクルで繰り返し投下 → 数万〜20万再生が安定
- **成果事例：2週間で3万人増・GW期間だけで2万人増**
- **NG：消して再投稿の無限ループ** → スパム判定でBAN

### バズネタの使い回し戦略
- 冒頭カット・文字ドアップ・CTA変更などAI重複判定されない微調整で5〜6回投稿
- 元動画240万再生 → 5〜6回目で7万人フォロワー増の事例
- 同じ動画の再掲でも効果あり（400万→300万→50万→82万と続けて再生数がつく）

### CTAの最適化
- 「こういう投稿してるからフォローしてね」と明示するだけで転換率が大幅改善
- **2段階CTA**：「次の投稿で配る」と予告 → フォロー誘導 → 百万再生で1.3〜1.6万フォロワー増
- **ダイジェストCTA**：過去投稿の冒頭フック4〜5枚まとめて「他にもこういう投稿してる」→ 転換率通常の3〜5倍

### 海外トレンド先取り
- TikTokでバズ → Instagram1〜2ヶ月遅れで展開すると効果的
- X（旧Twitter）のトレンドをインスタより先に察知し「日本に上陸しました」で投稿 → 9,800人増

### シーズナルタイミング戦略
- クリスマスは1ヶ月前ではなく**前日（12/23）に投稿** → 再生数が劇的に跳ね上がる
- 占い・不安系は**日曜夜8〜9時**が最効果（月曜への不安が最高潮）
- キャンペーン期間を逆算して3週間前から積み上げ投稿 → 爆発

## 8. マーケティングファネル（BUZZ BOOSTインスタ講座より）

### 基本構造
```
集客（認知） → 教育（価値観） → リスト獲得 → 販売 → 満足
   ↑               ↑               ↑          ↑
 リール          ストーリー        LINE公式    セミナー
 フィード        フィード          メルマガ     個別相談
```

### LINE/メルマガを挟む最大の理由
- インスタのフォロワー ≠ 「こちらからアタックできる顧客」
- **LINEはこちらからコンタクトを取れる（顧客リスト）**
- 何人にアタックできるか が商売で最も大切
- LINEは取得ハードルが低く・開封率が高い（メルマガより優先）

### LINE vs メルマガ
| | LINE | メルマガ |
|--|------|---------|
| メリット | 開封率高・ハードルが低い | BANリスクなし・コスト低 |
| デメリット | BANリスクあり・費用が高い | 開封率が低い・分析しづらい |

**結論：LINEとメルマガは合わせて取得する**

### LINEツールの重要度ランク
| ランク | 機能 |
|--------|------|
| S | シナリオ配信・回答フォーム・タグ管理・テンプレ |
| A | 流入経路分析・リマインダ配信 |
| B | リッチメニュー（意外と重要度は低い） |

### ファネルで数字が落ちている場所を特定する
- ライブを見ていない？
- LINEに入ったけどセミナー予約していない？
- iステップの文章が悪い？
- ▶ **どこのファネルで数字が落ちているか** を見ることが重要

## 14. NGワード・絶対にやってはいけないこと

### コンテンツNGワード
- 「絶対稼げる」「誰でも月○万円」「確実に」などの断言表現
- 個人成果には「個人差があります」の旨を必ず添える
- 受講生の顔出し・名前は本人許可取得後のみ

### アルゴリズム・アカウントBANリスク
- **トライアルリールの無限ループ（消して再投稿）** → スパム判定でBAN
- **8分に1回の超高頻度自動投稿** → アカウント凍結
- **GW中に全く同じ動画を大量投下** → シャドウバン
- **ThreadsでのAI生成の自己リプライ** → スパム判定リスク
- **リンクをボタンに巧みに隠す手法** → プラットフォーム規約違反
- **意図的な炎上** → 品格が下がる・諸刃の剣
- **過去PR投稿を隠して数値偽装** → クライアントとの信頼喪失
