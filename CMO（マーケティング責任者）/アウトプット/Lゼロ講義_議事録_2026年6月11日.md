## 議題別サマリー

### 1. 講師（さえ）の自己紹介・経歴
- 大学生時代から発信活動を始め、文字入れは独学でマスター
- ひたすら行動した結果が今の成果につながっている
- メンバーとの信頼関係が厚く、自身の紹介商品（にこせっけんなど）がコミュニティ内でも購入されている

### 2. 受講生の悩み（ストーリー・アフィリエイト全般）
- 参加者の多くが「全部悩んでいる」と回答（②④⑤が特に多い）
- まだ投稿を始めていない人もいて、全てが課題という状態

### 3. 日常ストーリーで親近感を作る方法
- **失敗談・日常のエピソード**が親近感を生む（餃子が塊になったエピソードなど、クスッと笑えるネタ）
- 子供・旦那さんとのやりとりが親しみやすさにつながる
- **失敗 vs 憧れポイントの違い**
  - 失敗：「あるある」「共感」で距離が縮まる
  - 憧れ：「自分もなりたい」という動機づけになる要素
  - → 両方をバランスよく混ぜるのが効果的

### 4. 質問ボックス・アンケートの活用
- アンケートには**全員に返信**（コピペでも可）→ 会話が続く
  - ちよの実践例：200人以上の回答→全員にコピペ返信→数人と会話が続いた
- **答えやすい質問設計**が重要（例：「黒派？赤派？」などの二択）
- アンケート回答がストーリーに採用されると嬉しいと感じる
- DM終わりどきの目安：会話が自然にひと区切りついたら次のアクションへ

### 5. 好きなものの共通性 → 急激な親近感
- 好きなものが一緒とわかると一気に親近感がわく（黒ペン・赤ペンの話など）
- 日常の小ネタが会話のきっかけになる

### 6. リールの鉄則：1秒勝負
- 視聴者はリールを**1秒で見るか止めるか判断**する
- ほとんどの人が「だらだらしているとき」「寝る前」「隙間時間」に視聴
- → 最初の1秒でつかむ工夫が必須

### 7. 関係構築タイプ（AタイプvsBタイプ）
- **Aタイプ：** 日頃から関係構築して売れる（全員がAを目指したいと回答）
- **Bタイプ：** 関係構築なしで売ろうとする
- 関係構築は難しいと感じる人が多いが、日常ストーリーの積み重ねが近道

### 8. ストーリー投稿の実践ヒント
- ストーリーは**1枚ずつ上げる**のが基本（まとめすぎに注意）
- 素材はSNS用フォルダに整理しておく
- **身バレ対応：** 少しずつ日常を出して人柄を伝えていく
- **載せないところを決める**（子供の行事の日など境界線を明確に）
- 投稿時間はある程度決めておくと習慣化しやすい

### 9. アフィリエイト商材選びの基準
- 「売れているから」だけでは選ばない → **自分が理由を言えるかどうかが基準**
- 使ってよかった体験・変えた理由を言語化できる商材を選ぶ
- 流行り商品（日傘など）を載せる場合も、自分の「使わない理由」を正直に語れることが信頼につながる
- **新商材PRは興味付けに数日使う**（いきなりリンクを貼るのではなく段階的に）
- 商材を変えた場合は「変えた理由」をしっかり伝える（例：マナラから別商品への切り替えなど）

## キーワード・学び

| テーマ | ポイント |
|---|---|
| 日常ストーリー | 失敗談・クスッとネタが親近感を生む。失敗と憧れはバランスよく |
| アンケート返信 | コピペでも全員返信が関係構築の鍵。数人と会話が続けば成功 |
| 1秒勝負 | リールは最初の1秒でスワイプされるか止まるかが決まる |
| 好きなものの共通性 | 二択アンケートや小ネタで急激に距離が縮まる |
| Aタイプを目指す | 関係構築型の発信が長期的な信頼とマネタイズにつながる |
| 商材選びの基準 | 「理由が言えるか」「自分で使ってよかったか」が判断軸 |
| 身バレ対策 | 載せないゾーンを決めた上で、少しずつ日常を出していく |
| 素材管理 | SNS用フォルダを作って素材不足を防ぐ |
