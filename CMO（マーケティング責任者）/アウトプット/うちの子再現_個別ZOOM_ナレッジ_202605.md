# うちの子再現アーティスト養成講座 個別ZOOM ナレッジ集
## 2026年5月｜石川さゆりさん 初回個別セッション より

---

## 受講生プロフィール（匿名化）

- **きっかけ**: テレビや情報収集中に偶然出会い、即決で申し込み
- **作る対象**: 17歳まで生きたワンちゃん（すでに他界）
- **動機**: 「常にピタッと横にくっついていてくれた存在。そばに置いてふと目に入るところにいてほしい」
- **不安点**: 骨組みからの立体化工程ができるか不安
- **特徴**: 思いつきで行動するタイプ。Zoomセミナー等には慣れている

---

## よくある受講生の不安（入会時）

| 不安 | 対応方法 |
|------|----------|
| 立体にする工程が難しそう | 1〜3ヶ月の動画が練習ステップになっている。順番にやれば形になる |
| 自分にできるか | 80代の方3名が未経験で完成させた実績を伝える |
| 聞くタイミングが分からない | 迷ったらすぐLINEでOK。遠慮せず聞いてもらう方が結果が良い |
| 対面の方がいいのでは？ | まずZoomで進めて、どうしても難しい場合はワークショップ（毎月20日）や個別来店も可 |
| 材料の購入方法 | 4ヶ月目以降に購入サイトをLINEで案内する |

---

## 受講生がうちの子を作りたい理由（パターン）

1. **寄り添いの記憶**：常に横にいてくれた存在を形にして、また「そば」に置きたい
2. **グリーフケア**：ぼんやりした気持ちの消化。形として思い出を昇華させたい
3. **声かけ・会話の継続**：骨壷に手を合わせるだけだったが、形になると声かけが習慣になったという声多数
4. **自分で作ることへの価値**：「誰かに頼む」ではなく、自分の愛情を込めた唯一の作品にしたい

## 重要な技術指導ポイント

### ① 硬さが最重要
- **NG**: 柔らかすぎる → 形が崩れる・毛が抜ける
- **OK**: 弾力はあるが形が崩れない硬さ
- **初心者向けアドバイス**: 硬めでOK。触り心地は少し変わるが形は作れる
- **目安**: ギュッとしても元に戻る、形が崩れない状態

### ② 失敗しても修正できる
- 大きくなりすぎた部分 → ハサミでカットして材料を足せば戻せる
- 針と糸の作品と違い「そこまで戻る」必要がない → 自由度が高い

### ③ 作る順番は自由
- 講座の順番で進めるのが基本だが、慣れてきたら得意な部分から作っていいと伝える
- 例：体を最初に仕上げたい、顔から先に作りたい → どちらでもOK

### ④ 色は1色より混色でリアルに
- 単色だとぬいぐるみっぽくなる
- 茶色でも複数の色を混ぜることでリアルな表現になる
- 材料購入前に写真を見て一緒に色を相談する

### ⑤ 温かみが大きな価値
- 羊毛フェルトは触るとぬくもりがある（冷たくない）
- 「生きている感じがする」という受講生の声多数

## 心理的サポートの声がけパターン

### 入会動機を深掘りする質問
- 「どんな未来をイメージして作りたいですか？」
- 「作品が手元に届いた時、どんな風に一緒にいたいですか？」

### 1体目へのプレッシャーを取る声がけ
- 「1体目は完璧じゃなくていい。作ってみると見えてくるものがある」
- 「作るうちに欲が出てくる。それが成長のサイン」
- 「愛情を込めて、その子を思いながら作る過程を楽しんでほしい」

### 受け取った方の変化（実例として共有）
- 「家族でいい思い出の話をするようになった」
- 「骨壷に手を合わせるだけだったのが、声かけが習慣になった」
- 「マイナスじゃなくプラスの方向で、これからの未来に向けて思い出と生きていく選択をしている方が多い」

## オペレーション・サポート体制メモ

| 項目 | 内容 |
|------|------|
| 質問受付 | LINEで随時（タイム差あり・子供が小さいため）|
| Zoom相談 | 希望があれば個別対応 |
| 月次ワークショップ | 毎月20日（対面・作品持参も可） |
| 材料案内 | 4ヶ月目以降にLINEグループノートでリンク共有 |
| 進度管理 | 早く終わったらLINEで連絡→次の動画を早めに配信 |

## 講師の想い・哲学（伝え方の参考）

> 「80代3名が全く未経験で1体ずつ完成させている。形には必ずなる。」
