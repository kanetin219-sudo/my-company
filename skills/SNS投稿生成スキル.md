ブランドの世界観・文章スタイルを守りながら、各媒体の特性に最適化された投稿を作成する。

## Threads 投稿ルール

### 基本情報
- 文字数：500文字以内（理想は200〜400文字）
- 読者層：20〜40代・情報感度が高い人
- 伸びる投稿の特徴：日常・本音・ストーリー性・共感・気づき

### 文章構成
```
①つかみ（1〜2行）
　→ 思わず止まる一言・問いかけ・本音の吐露

②本文（3〜8行）
　→ 日常の出来事・気づき・体験談・考えをストーリー形式で語る

③締め・行動喚起（1〜2行）
　→ 共感を求める問いかけ・次への一歩・感謝の言葉
```

### 絵文字ルール
- 使用量：1投稿につき0〜3個まで（使いすぎない）
- 使う場所：文末・強調したい箇所のみ
- 使わない絵文字：派手すぎるもの・ビジネス感が強すぎるもの
- おすすめ絵文字：🐾🌿☀️🙏💬✨（温かみ・自然・感謝系）

### ハッシュタグルール
- Threadsではハッシュタグは原則使用しない（アルゴリズム上効果が低く、ノイズになりやすい）
- どうしても使う場合は1〜2個、投稿末尾に添える程度

### NGワード・表現
- 「必見」「絶対」「稼げる」などの誇大表現
- 過度なセールス・強引なCTA
- 他者を下げる比較表現

### 投稿例テンプレート（Threads）
```
今日、利用者さんに「来るのが楽しみになった」って言われてさ。

正直、最初は通所が安定するか不安やったんよね。
でもその一言で、やっててよかったって心から思えた。

福祉の仕事って数字じゃ見えにくい部分が多いけど、
こういう瞬間があるから続けられる。

ありがとうって言葉が、一番のエネルギーになるちゃ🙏
```

## Instagram 投稿ルール

### 基本情報
- キャプション文字数：2200文字以内（理想は500〜1000文字）
- 読者層：20〜40代女性・副業志向のママ層
- 伸びる投稿の特徴：保存される情報・ビジュアルと連動・キャプションの読みやすさが重要

### 文章構成
```
①つかみ（1〜2行）
　→ ターゲットが「自分のことだ」と感じる問いかけ・悩みの言語化

②本文（情報・ストーリー・価値提供）
　→ 読んで得になる情報 or 感情が動くエピソード
　→ 箇条書き・改行を活用して読みやすく整える

③締め・保存/フォロー促進（1〜3行）
　→「保存しておくと便利です」「同じ気持ちの人はコメントで教えて」など
```

### 絵文字ルール
- 使用量：1投稿につき5〜15個（Threadsより多めでOK）
- 使う場所：行頭の装飾・重要ワードの強調・箇条書きの頭
- 読みやすさを最優先にし、乱用しない
- おすすめ絵文字：🐾🌸💡📱🙌✨🌿💕🔖（親しみ・情報・女性向け）

### NGワード・表現
- 「稼げる」「月収〇〇万」などの誇大収益表現
- 医療・福祉に関する根拠のない効果・効能の主張
- 他社・他者を否定・比較する表現
- 個人情報・利用者の顔が写った画像の無断使用

### 投稿例テンプレート（Instagram）
```
子育てしながら在宅で収入を得るって、
本当に可能なの？🤔

結論、できます。
でも「正しい順番」を知らないと遠回りになる。

私がLゼロで教えてることは、
華やかなスキルじゃなくて
「再現性のある仕組みづくり」💡

✅ SNSの使い方を正しく学ぶ
✅ 小さく始めて、徐々に広げる
✅ 自分の生活スタイルに合わせてカスタム

派手な成功談より、
地道に積み上げた人が長く続くちゃ🌿

今まさに「何から始めればいいかわからない」
って悩んでる人、コメントで教えてね🙌

この投稿、あとで見返せるように
保存しておくと便利ですよ🔖
```

## 投稿生成時の確認事項

投稿を生成する前に、以下を確認・明示してから作成する。

1. **媒体**：ThreadsかInstagramか（または両方）
2. **テーマ・題材**：何について投稿するか
3. **事業**：どの事業に関連する投稿か
4. **目的**：認知拡大 / 共感獲得 / 問い合わせ誘導 / 保存促進 など
5. **トーン調整**：いつもより感情的に / 情報寄りに など特別な指示があれば反映

## アウトプット保存ルール
- 生成した投稿文はCMOのアウトプットフォルダに保存する
- ファイル名は「YYYYMMDD_媒体名_テーマ.md」の形式で統一する
  - 例：`20260422_Threads_保護犬猫カフェ日常.md`
  - 例：`20260422_Instagram_Lゼロ在宅ワーク.md`
