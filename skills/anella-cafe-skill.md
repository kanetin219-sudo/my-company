## ① 入場管理システム

### 機能一覧
- 複数組の同時管理（A組・B組ではなくお名前で管理）
- 来店回数選択（新規/2回目/3回目/4回目以上）※必須・プルダウン
- 5分間の無料インターバル（準備時間・課金は5分後から）
- リアルタイムタイマー・料金計算（1秒ごと更新）
- 30分超えで赤くハイライト＋「延長中」バッジ
- ガチャ回数管理（1回¥200・会計時に加算）
- localStorageでデータ保存（更新・再起動してもデータが消えない）
- 会計時にGoogleスプレッドシートへ来店回数を自動記録

### 料金体系
| 区分 | 最初の30分 | 延長15分ごと |
|------|-----------|------------|
| 大人（通常） | ¥1,000 | ¥400 |
| 大人（シニア割・障害者割引） | ¥500 | ¥200 |
| 子供 | ¥500 | ¥200 |
| 口コミ割 | 全員半額 | 全員半額 |

### 割引ルール
- シニア割・障害者割引：本人＋同伴者1名（最大2名）まで割引
- 口コミ割：全員半額（他の割引と併用不可）

### スプレッドシート記録仕様
- シート名：`記録`
- 列構成：A=日付 / B=新規 / C=2回目 / D=3回目 / E=4回目以上
- 通信方式：GETリクエスト（`?visit=新規` のようにパラメータで送信）
- 日付ごとに行を作成し該当列に加算

### GASコード（入場管理用）
```javascript
function doGet(e) {
  var spreadsheetId = '1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo';
  var sheet = SpreadsheetApp.openById(spreadsheetId).getSheetByName('記録');
  var visit = e.parameter.visit;
  var today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd');
  var lastRow = sheet.getLastRow();
  var todayRow = -1;
  for (var i = 2; i <= lastRow; i++) {
    if (sheet.getRange(i, 1).getValue() === today) {
      todayRow = i;
      break;
    }
  }
  if (todayRow === -1) {
    todayRow = lastRow + 1;
    sheet.getRange(todayRow, 1).setValue(today);
  }
  var colMap = {'新規': 2, '2回目': 3, '3回目': 4, '4回目以上': 5};
  var col = colMap[visit];
  if (col) {
    var current = sheet.getRange(todayRow, col).getValue() || 0;
    sheet.getRange(todayRow, col).setValue(current + 1);
  }
  return ContentService.createTextOutput('ok').setMimeType(ContentService.MimeType.TEXT);
}
```

## ハマったポイント・技術的注意事項

### GitHub Pages
- ファイル反映に数分かかることがある
- ファイル名に `__` が付くとURLが不安定
- Settings → Pages → Branch: main で有効化が必要

### Googleアカウント
- 複数アカウントがあるとGASデプロイ時に干渉する
- `anellacafeoita@gmail.com` で統一して操作
- シークレットモードで該当アカウントのみでログインすると安定

### Apps Script
- **必ずスプレッドシートから「拡張機能 → Apps Script」で開く**
  （直接script.google.comから作ると紐付かない）
- シート名は必ず正確に（大文字小文字・スペース注意）
- デプロイ設定：「次のユーザーとして実行：自分」「アクセス：全員」
- コード修正後は「デプロイを管理 → 新しいバージョンで更新」が必要
- POSTリクエストはCORSエラーが出やすいのでGETリクエストを使う
- GASのURLはデプロイのたびに変わるので都度HTMLに反映する

### localStorage
- ブラウザごとに別々に保存される（MacとiPadでデータ共有不可）
- iPadのSafariで統一して使う運用にした

### iPadのSafari
- ローカルのHTMLファイルはJavaScriptが動かない制限がある
- GitHub PagesのURLで開くと全機能が動く
- ホーム画面に追加するとアプリのように使える

### LINE Messaging API
- チャンネルアクセストークンをGASのスクリプトプロパティに保存（コードに直書きしない）
- お客様がLINE公式アカウントを友だち追加していることが前提
- Push Message APIでお客様のLINE IDに直接送信
