# アネラカフェ週報生成・LINE配信システム セットアップガイド

## システム概要
毎週木曜日に、スタッフが撮った写真を AI が自動分析して週報を生成し、LINE 公式アカウントから利用者・家族に配信するシステムです。

**公開URL**: https://kanetin219-sudo.github.io/anella-cafe/weekly-report.html

---

## Step 1: Google Apps Script のセットアップ

### 1-1. GAS で Web App を作成

1. https://script.google.com を開く
2. 「新規プロジェクト」を作成
3. ファイル `anella-weekly-report-claude-proxy.gs` をすべてコピー
4. GAS のエディターに貼り付け

### 1-2. デプロイ

1. 「デプロイ」をクリック
2. 「新しいデプロイ」を選択
3. 以下を設定：
   - **種類**: ウェブアプリ
   - **実行形式**: 現在のユーザーとして実行
   - **アクセス権限**: 全員（匿名ユーザーを含む）
4. 「デプロイ」をクリック
5. **Web App URL をコピー**（後で使用）

例: `https://script.google.com/macros/d/AKfycbz...../usercontent`

---

## Step 2: 週報ツールの初期設定

### 2-1. ツールにアクセス

ブラウザで以下を開く：
https://kanetin219-sudo.github.io/anella-cafe/weekly-report.html

### 2-2. API 設定画面を開く

1. ログイン画面の下にある「⚙️ API設定」をクリック
2. 以下を入力：

| 項目 | 説明 | 入手方法 |
|------|------|--------|
| **ログインパスワード** | スタッフがツールを開くときのパスワード | 自由に設定（例：anella2026） |
| **Claude APIキー** | OpenAI API キー | Anthropic コンソール |
| **GAS Web App URL** | Step 1 でコピーした URL | `https://script.google.com/macros/d/...` |
| **LINE トークン** | LINE Messaging API のチャンネルアクセストークン | LINE Developers |

### 2-3. Claude APIキーを取得

1. https://console.anthropic.com/account/keys にアクセス
2. ログイン（Google や GitHub アカウント）
3. 「新規キーを作成」をクリック
4. キーをコピー（`sk-...` で始まる）

### 2-4. LINE トークンを取得

1. https://developers.line.biz/ にログイン
2. 「アネラカフェ大分店」のチャンネルを選択
3. 「チャネルアクセストークン」をコピー（`Bearer ...` 形式）

### 2-5. 設定を保存

1. すべて入力したら「設定を保存」をクリック
2. 確認画面が出たら OK

---

## Step 3: スタッフ向け利用手順

### 毎週木曜日午前の作業

1. **ツールを開く**
   - URL: https://kanetin219-suo.github.io/anella-cafe/weekly-report.html

2. **ログイン**
   - パスワードを入力（初期設定で決めたもの）

3. **写真をアップロード**
   - 月〜水で撮りだめた写真を 1〜5 枚選択
   - ドラッグ&ドロップ または タップで選択
   - 「メイン」に設定する写真を選択（最初の写真が自動選択）

4. **週報を生成**
   - 「📝 週報を生成する」ボタンをクリック
   - AI が自動で 3 つのテキストを生成
   - 🐾 今週のひとこと
   - 🐶🐱 今週の子たち
   - ✨ みんなの作業風景

5. **内容を確認・修正**
   - プレビュー画面でテキストを確認
   - 修正したい場合は、テキストをタップして編集
   - 満足したら「💬 LINEに配信」ボタンをクリック

6. **LINE 配信完了**
   - 利用者・家族に自動配信

## トラブルシューティング

### ❌ "CORS エラー" が出た場合
→ GAS Web App URL が正しく設定されているか確認してください

### ❌ "Claude API エラー" が出た場合
→ API キーが正しいか確認
→ API キーの有効期限を確認
→ クレジット残高を確認（https://console.anthropic.com/account/billing）

### ❌ "LINE 配信エラー" が出た場合
→ LINE トークンが正しいか確認
→ LINE 公式アカウントが正しく設定されているか確認

### ❌ "写真がアップロードできない" 場合
→ 写真サイズが大きすぎないか確認（推奨: 5MB以下）
→ ブラウザのキャッシュをクリア（Cmd+Shift+Delete）

---

## 重要な情報

- **毎週木曜に自動配信** - 火曜の深夜に設定変更可能
- **写真は最大5枚まで** - 多すぎるとAI生成に時間がかかります
- **テキストは手動編集可能** - AI生成後に修正できます
- **LINE 配信先は「全員」** - ブロードキャスト機能を使用
