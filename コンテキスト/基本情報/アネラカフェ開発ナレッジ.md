# アネラカフェ大分店 入場管理システム 開発ナレッジ

## プロジェクト概要
保護犬猫カフェ「アネラカフェ大分店」の入場管理をデジタル化するHTMLツール。
就労継続支援B型事業所としても運営しており、トリミングサロンも併設。

## 料金体系

| 区分 | 最初の30分 | 延長15分ごと |
|------|-----------|------------|
| 大人（通常） | ¥1,000 | ¥400 |
| 大人（シニア割・障害者割引） | ¥500 | ¥200 |
| 子供 | ¥500 | ¥200 |
| 口コミ割 | 全員半額 | 全員半額 |

### 割引ルール
- **シニア割・障害者割引**: 本人＋同伴者1名の最大2名まで割引適用。残りは通常料金
- **口コミ割**: 大人・子供全員が入場料半額（他の割引と併用不可）
- **小学生未満**: 無料（子供カウントに含まない）

## 主要機能

### 入場管理
- 複数組の同時管理（A組・B組…ではなく名前で管理）
- 入場時に以下を入力：
  - お名前（必須）
  - 来店回数（必須・プルダウン）：新規 / 2回目 / 3回目 / 4回目以上
  - 大人・子供の人数
  - 割引選択：シニア割 / 障害者割引 / 口コミ割
- **5分間の無料インターバル**：入場直後は「準備中」表示、5分後から課金開始

### タイマー・料金
- リアルタイムタイマー（1秒ごと更新）
- 現在料金をリアルタイム表示
- 30分超えで赤くハイライト＋「延長中」バッジ表示

### ガチャ
- 各グループカードに「🎰 ガチャ −/＋」ボタン
- 1回¥200
- 会計時に料金に加算・明細表示

### 会計
- 入場時刻・退場時刻・滞在時間・料金内訳を表示
- 会計完了時にGoogleスプレッドシートへ自動記録

## Googleスプレッドシート連携

### スプレッドシート情報
- **ID**: `1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo`
- **URL**: `https://docs.google.com/spreadsheets/d/1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo/edit`
- **シート名**: `記録`
- **列構成**: A=日付 / B=新規 / C=2回目 / D=3回目 / E=4回目以上

### Apps Script
- **GASのURL**: `https://script.google.com/macros/s/AKfycbwwRaUFzoVqobnN_n6zgc6YRTe2zo0MOzakkUHxrnCE9kQxUS_lXcxzQia3AVvooG5Hig/exec`
- **通信方式**: GETリクエスト（`?visit=新規` のようにパラメータで送信）
- **記録方式**: 日付ごとに行を作成し、来店回数の列に加算

### Apps Scriptコード
```javascript
function doGet(e) {
  var spreadsheetId = '1sF16Oev_i-_Xt1FT0QGfcHkWiBu0a8ARaOft1Lxngzo';
  var sheet = SpreadsheetApp.openById(spreadsheetId).getSheetByName('記録');
  var visit = e.parameter.visit;
  var today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy/MM/dd');
  var lastRow = sheet.getLastRow();
  var todayRow = -1;

  for (var i = 2; i <= lastRow; i++) {
    if (sheet.getRange(i, 1).getValue() === today) {
      todayRow = i;
      break;
    }
  }

  if (todayRow === -1) {
    todayRow = lastRow + 1;
    sheet.getRange(todayRow, 1).setValue(today);
  }

  var colMap = {'新規': 2, '2回目': 3, '3回目': 4, '4回目以上': 5};
  var col = colMap[visit];
  if (col) {
    var current = sheet.getRange(todayRow, col).getValue() || 0;
    sheet.getRange(todayRow, col).setValue(current + 1);
  }

  return ContentService.createTextOutput('ok').setMimeType(ContentService.MimeType.TEXT);
}
```

## ハマったポイント・注意事項

### GitHub Pages
- ファイルをアップロード後、反映に数分かかることがある
- ファイル名に `__` が付くとURLが不安定になるので注意
- `Settings → Pages → Branch: main` で有効化が必要

### Googleアカウント
- 複数アカウントがあるとApps Scriptのデプロイ時に干渉する
- `anellacafeoita@gmail.com` で統一して操作する
- シークレットモードで該当アカウントのみでログインすると安定する

### Apps Script
- スプレッドシートから「拡張機能 → Apps Script」で開かないと紐付かない
- シート名は必ず「記録」にする（大文字小文字・スペース注意）
- デプロイ設定：「次のユーザーとして実行：自分」「アクセス：全員」
- POSTリクエストはCORSエラーが出やすいのでGETリクエストに変更した
- コードを修正したら「デプロイを管理 → 新しいバージョンで更新」が必要

### localStorageについて
- ブラウザごとに別々に保存されるためMacとiPadでデータは共有されない
- iPadのSafariで統一して使う運用にした
