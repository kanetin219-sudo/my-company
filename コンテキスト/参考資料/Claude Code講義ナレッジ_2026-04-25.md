## 学んだこと・重要ポイント

### Claude Codeとは何か
- **PC内部で直接動く AI**。チャットGPTやGeminiと異なり、ローカルのファイルを読む・書く・消す・実行することができる
- 大規模ファイル処理・長時間稼働・多様なツール連携が可能で、他AIと一線を画す
- 2025年初頭はCLI版（ターミナル操作）のみだったが、デスクトップ版（GUI）の登場により一気に普及
- Googleが約6.4兆円（100億ドル）出資を決定（2026年4月25日発表）するほど業界注目の存在

### 使い方の種類（4種類）
1. **CLI版**（ターミナル）：エンジニア向け、高度な操作
2. **デスクトップ版**（GUI）：**初心者推奨**。マウス操作でフォルダ指定・モード切替ができる
3. **Web版**：ほぼ使わない
4. **IDE拡張版**（VS Code等）：開発者向け

> **結論：デスクトップ版を使えばOK**。変なエンジニア風の人が「ターミナル使えないの？」と言ってきても気にしない。

### 料金体系
- **Proプラン（約3,000円/月）**：使用可。ただし長時間作業で制限がかかることがある
- **Maxプラン（約15,000円/月）**：推奨。制限が少なく、自動モードも使える
- **Max 200プラン**：ヘビーユーザー・開発者向け
- **無料では使用不可**（課金必須）

### 権限とファイルアクセス（最重要）
- PCはディレクトリの階層構造になっており、Claude Codeは「どのフォルダで動かすか」を最初に指定する必要がある
- **指定フォルダ内のファイル全てにアクセス可能**。最上位を指定するとPC全体のデータが操作・削除できてしまうため危険
- **初心者は必ず空の専用フォルダ（例：「ClaudeCodeテスト用」）から始める**こと

### 5つの権限モード
| モード | 内容 |
|---|---|
| 許可を確認 | 全操作で確認が入る（安全だが遅い） |
| 編集を承認 | ファイル編集時のみ確認 |
| プランモード | 実行前にClaudeが計画を提示して確認 |
| 自動モード | ほぼ全て自動（Maxプランで使用可） |
| バイパスモード | 全自動・確認なし（**危険・上級者のみ**） |

> **推奨**：大規模作業はまず「プランモード」でClaudeに計画確認 → OKなら「自動モード」へ移行

### モデルの使い分け
| モデル | 特徴 | 使いどころ |
|---|---|---|
| Opus 4.7 | 最高精度・高コスト | 難しいバグ修正・重要な開発場面 |
| Sonnet 4.6 | バランス型・**普段使い推奨** | 通常作業全般 |
| Haiku 4.5 | 高速・低コスト | 単純なファイル操作・確認作業 |

- Proプランは使用量に注意：簡単な作業はSonnet・Haiku で節約、ここぞという場面でOpus
- 「節約のため安いモデルを使って失敗 → やり直し」は逆にコスト増。最初からOpusという考え方もある

## 具体的なコマンド・使い方

### 基本操作
- **作業フォルダの指定**：アプリ起動 → 「コード」タブ → ローカルを選択 → フォルダを開く（デスクトップ推奨）
- **ファイルパスの確認**：Claude Codeに「ファイルパス出して」と入力 → コピーしてFinderの⌘Shift+G（Windowsはwindows+R）でペースト → 該当フォルダに一発で移動
- **ファイルをClaudeに指定**：Optionキー+右クリック →「パス名をコピー」→ Claude Codeに貼り付け

### プロンプトの考え方
```
プロンプト = 「理想の状態」と「現状」のギャップを埋めるための言葉
```
- 「あなたはプロの○○です」などのロールプロンプトは不要
- やりたいこと・欲しい状態をそのまま平易な言葉で伝えるだけでOK
- **出戻りを防ぐには「Ask User Question（アスクユーザークエスチョン）ツール」を活用**：自分の解像度が低いと感じたら、Claudeに先に質問してもらう

### 実践例
```
# タイマーアプリ作成
「簡単なタイマーを作ってください」

# ファイル整理
「デスクトップに大量のファイルを散布して散らかしてください（30個程度）」
→ 「散らかしたファイルをきれいに整理してください」

# 名刺データのExcel化
「カードというフォルダにある名刺情報を全て読み込み、Excelに整理してください。Excelファイルはアウトプットしてください」

# 領収書のファイル名整理
「レシートフォルダの領収書を全てスキャンし、ファイル名をYYYY_MMDD_宛名_ただし書き形式に変更して、Excelにもまとめてください」

# 大規模タスク管理システム（Ask User Questionを使う場合）
「タスク管理システムを作りたい。Ask User Questionを使って、まず質問してくれ」
```

### MCP（外部サービス連携）
- 設定場所：左下メニュー →「設定」→「コネクタ」
- 主要連携先：Gmail・Googleカレンダー・Notion・Slack・GitHubなど
- **活用例**：Googleカレンダーを連携し「一週間分の空き時間（1時間・前後30分余裕あり）を教えて」→ 日程調整文を自動生成

```
# GmailMCPを使ったパーソナライズメール自動生成
「名刺フォルダをスキャンしてExcelにまとめ、GmailMCPを使って全員分の会社・役職に合わせたAI研修営業メールの下書きを20件作成してください」
```

> **注意**：メールは「下書き保存」まで。自動送信は設定しないこと。

### スキル（Skills）
- **一度設定した作業手順を再利用できる機能**（GPTsの上位版イメージ）
- スキルはMDファイルベースで、所定の場所に保存することで`/スキル名`で呼び出し可能
- スラッシュコマンドで呼び出し：`/道草スライド` → 自動でPPTXを生成
- スキルは共有・配布が可能

### チームエージェント（Team Agent）
- Claude Code自体が複数の**サブエージェントを並列起動**して協調作業する機能
- 指示例：「○○についてリサーチしてください。チームエージェントを組んで、SNSからの調査・ウェブ記事からの調査・YouTubeからの調査・Wikipediaからの調査の4つの並列エージェントを組んでください」
- エージェント同士は連携しながら作業し、作ったSlackクローンの画面で会話させることも可能

## 活用できるシーン

### 業務効率化
- **名刺・領収書のデジタル化**：写真フォルダを読み込んでExcel一括出力
- **ファイルの自動整理・命名規則統一**：散乱したファイルをカテゴリ・日付形式で整理
- **日程調整文の自動生成**：Googleカレンダー連携で空き時間を瞬時に出力
- **パーソナライズ営業メールの下書き作成**：名刺データ→会社・役職に合わせた文章を大量生成

### 開発・コンテンツ制作
- **ウェブアプリ・タスク管理システムの開発**：NoCodeでも本格的なアプリが作れる
- **スライド自動生成**：ノートのメモをそのまま貼り付けるだけで百枚規模のPPTX作成
- **動画編集の自動化**：スキルを使って繰り返し処理
- **大規模リサーチ**：複数のエージェントが並列でSNS・Web・YouTube等から情報収集

### GitHubツールの活用
- GitHubで公開されているツールをClaude Codeで簡単にインストール・使用できるようになった
- 注意：スター1000以上・信頼できる人の紹介など安全確認は必要

## かねちんの会社への応用方法

### 支援現場（CWO）
- **スタッフの日程調整・シフト作業**：Googleカレンダー連携で空き時間の自動抽出・調整文生成
- **支援記録のファイル整理**：写真・ドキュメントを日付・利用者名ルールで自動命名・分類
- **スタッフ向け資料の自動作成**：研修用スライドをスキル化して繰り返し生成

### 営業・顧客管理（CSO）
- **展示会や名刺交換後の営業メール自動化**：名刺写真 → Excel → Gmailメール下書きを一括生成
- **提案書・顧客資料のスライド生成**：顧客情報メモを貼り付けてPPTX自動作成
- **Googleカレンダー連携での商談調整効率化**

### マーケティング（CMO）
- **SNS投稿・LP・台本の自動生成**：テンプレート化したスキルを使って繰り返し生成
- **競合・市場リサーチ**：チームエージェントでSNS・Web・YouTube等を並列リサーチ
- **チームエージェントを使った定期タスク自動化**（エゴサ→新マーケ施策立案→メルマガ作成の流れ）

### プロダクト・企画（CPO）
- **機能仕様・企画書の管理システム開発**：タスク管理・ロードマップ管理ツールをサクッと作成
- **要件定義のサポート**：Ask User Questionツールで曖昧な仕様を対話型で明確化

### 財務（CFO）
- **領収書の一括整理**：写真フォルダを読み込んでExcel出力・ファイル名自動リネーム → 税理士への受け渡し工数を大幅削減

### 組織全体（AIエージェントネイティブ化）
- **スキルの社内共有**：一人が作ったスキル（手順書）をチームに配布して業務標準化
- **チームエージェントで会社の「AI組織」構築**：コンテンツ提案→作成→スライド化→動画化→PR→エゴサ→次の施策…という自律的なAI業務フローの構築
- クロードコードを使いこなしている経営者とそうでない経営者は、「AIの解像度の差」として発言から分かってしまう時代になっている

## 補足メモ（講師コメントより）

- **プロンプトより「理想の言語化」が大事**：自分がやりたいことを言語化できない人にはクロードコードは使いこなせない。まず「理想状態」を明確にすること
- **出戻りのコスト**：Claude Codeは1時間以上作業することも多い。最初の指示（要件定義）をしっかり行うことが最大のコスト削減策
- **音声入力の推奨**：タイピング名人よりも音声入力の方が速い。アクアボイス・タイプレス・VoiceOS等を活用
- **セキュリティへの注意**：バイパスモードは使いすぎない。PCの重要データがあるフォルダをClaudeに渡さない。メールは下書きどまりで自動送信させない
